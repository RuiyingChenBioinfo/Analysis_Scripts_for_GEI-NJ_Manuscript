GEI-NJ tutorial

Version 0.2.0.4. This example uses matched SNV depth and ALT ratio matrices to construct a rooted cell relationship tree. Install the package and RapidNJ as described in the README.

1. Load and validate the inputs

import anndata as ad
from gei_nj import comb_depth_ratio, filter_snvs, assign_state, zero_filling, build_nj

ad_depth = ad.read_h5ad("unit_depth.h5ad")
ad_ratio = ad.read_h5ad("unit_ratio.h5ad")
adata = comb_depth_ratio(ad_depth, ad_ratio)

Rows are cells or cell groups and columns are SNVs. Inputs must have matching, unique names. Depths are finite, nonnegative integer counts. At positive depth, ratios are finite observed ALT/total values in [0, 1]. At zero depth, use 0 or NaN; both represent missing data. Input NaNs generate a warning, and positive-depth NaNs raise an error. Keep raw ratios rather than rounded or pre-discretized values. The combined object stores original ratios in X and per-entry total sequencing depths in layers["total_depth"].

2. Filter SNVs

filtered = filter_snvs(
    adata,
    min_total_depth=5,
    remove_germline=True,
    min_callable_cells_germline=3,
    min_pooled_ratio_germline=0.90,
    min_E_germline=10,
)

Retain SNVs with depth summed across cells of at least 5. Candidate homozygous ALT germline sites are removed when at least three cells have positive depth and either their pooled ALT ratio is at least 0.90 or their all-ALT e-value is at least 10. The three parameters ending in _germline apply only when remove_germline=True. This identifies candidate sites and does not confirm their biological origin.

Optionally provide a headerless, single-column TSV with exact identifiers matching var_names:

filtered = filter_snvs(
    adata,
    exclude_snvs="examples/organelle_SNV_candidates.tsv",
)

The example list is user-specified and is not applied automatically. Replace it with loci appropriate to the dataset. Setting remove_germline=False disables candidate germline filtering but retains depth and user-list filtering.

3. Assign states and fill non-callable entries

two_state = assign_state(filtered, method="two-state", state_low=0.10)
two_state = zero_filling(two_state, min_callable_depth=1)

Observed ratios below 0.10 become 0; ratios at or above 0.10 become 1. Zero-filling then sets entries with depth below 1 to 0. Increasing min_callable_depth also fills positive-depth entries below the new threshold. Other entries keep their selected states. assign_state() writes a temporary state layer. Zero-filling stores the result in layers["zero_filled_state"], stores the callability mask in layers["callable"], and removes the temporary state layer. Both steps leave the original ratios in X unchanged. To repeat zero-filling or change its depth threshold, rerun assign_state() and then zero_filling().

4. Construct and root the tree

tree = build_nj(
    two_state,
    do_plot=True,
    wls_weight_power=2,
    use_branch_lengths=False,
    show_leaf_labels=True,
    savepath="geinj_tree.pdf",
    newick_path="geinj_tree.nwk",
)

Tree construction reads layers["zero_filled_state"], and RapidNJ uses L1 distances between real cells. WLS then fits the position of an all-reference profile on the fixed NJ tree and roots at its attachment point. The returned tree contains real cells only. WLS weights are (1 + distance_to_reference) ** -2 by default.

The default plot aligns the tips to show topology. To draw according to branch lengths, use use_branch_lengths=True. Both options use the same tree and root. Saved Newick retains the computed branch lengths; these are not calibrated mutation counts or elapsed time.

For group colors, provide an observation column, for example group_key="group", when that column is present. To save a tree without making a plot:

tree = build_nj(two_state, do_plot=False, newick_path="geinj_tree.nwk")

5. Keep continuous ALT ratios as an alternative

continuous = assign_state(filtered, method="continuous")
continuous = zero_filling(continuous, min_callable_depth=1)
tree_continuous = build_nj(
    continuous,
    do_plot=False,
    newick_path="continuous_tree.nwk",
)

This alternative uses the same filtering, zero-filling, L1, and WLS steps. It changes only the state representation. Preprocessing functions copy by default, so the filtered input can be reused. Original ratios remain in X and are used when changing the state representation. For this method, observed ratios are assigned directly as continuous states.
